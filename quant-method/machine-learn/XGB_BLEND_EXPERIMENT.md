# XGBoost 与一日反转因子融合实验

- 输入模型：当前验证集选择出的 `reg:pseudohubererror` XGBoost（25 棵树）
- 融合方式：先对模型分数和一日反转因子分别做逐日横截面 RankNorm，再进行线性融合
- 融合公式：`score = 0.25 * model + 0.75 * one_day_reversal`
- 选择标准：只使用验证集平均 Rank IC，Rank IC 相同时比较 Rank ICIR
