# AlphaX 本地研究工作台

在仓库根目录，用已安装 AlphaX 核心依赖的 Python 启动服务。

```bash
python report/web/server.py
```

打开 <http://127.0.0.1:8765>。可用 `--port 8877` 切换端口。服务监听本机地址。因子挖掘需要同一 Python 环境安装 LangGraph，安装方式见 [依赖说明](../../requirements/README.md#可选运行依赖与静态检查)。

## 研究流程

1. **系统设置**。填写模型、API 基础地址和密钥，配置特征面板、交易日历、因子库扫描路径、实验窗口和预算。使用 DeepSeek 时可将地址留空，密钥也可从服务环境的 `DEEPSEEK_API_KEY` 读取。自定义模型填写兼容 Chat Completions 的基础地址，例如服务的 `/v1` 路径，密钥也可从 `ALPHAX_LLM_API_KEY` 读取。界面填写的密钥仅保存在当前服务进程内。其余设置保存在 `report/web/.runs/settings.json`。
2. **因子挖掘**。用自然语言描述研究假设并提交。Miner 将假设用作模型提案上下文，按系统设置执行候选生成、训练反馈和准入检查。页面实时更新阶段和日志，任务完成后可打开生成的因子库。假设与 Miner 产物保存在对应任务目录。
3. **因子库**。扫描设置指定的目录与工作台产物，按实验来源展示因子定义、假设及可用的 1 日验证期 Rank IC。可搜索和筛选「已准入」「研究候选」「未准入」「缺少评估」。等级沿用来源实验的准入记录，不同实验适用各自的门槛。
4. **独立回测**。选择因子来源和纳入范围。工作台固定所选候选定义，运行 `run_pipeline.py`，按配置完成训练、滚动准入、策略验证及留出评估。结果页可切换已完成实验，查看留出期净值、样本等权参考、收益、Sharpe、回撤及冻结策略。回测沿用美股主线的日内执行口径，面板应包含显式标签日期和所选因子所需特征。历史因子在来源实验已见的数据区间上重跑时，结果按回顾性研究解读。

同一服务会话可同时运行一个任务。任务日志保留在当前会话，工作台产物落盘于 `report/web/.runs/`，服务重启后仍可读取已完成的因子和回测结果。

## 其他页面

- **研究总览**展示冻结四因子净值、两档成本、匹配指数代理和周频 XGBoost 配对案例。
- **Agent loop**展示现有历史研究的提案、训练折回测、反馈修订及最终准入统计。
- **实验对照**展示四因子基线、增强组合和后续冻结检验。
- **运行中心**可启动离线示例、核心冒烟测试和 S&P 500 流水线预检，也保留 DeepSeek、周频 XGBoost 配对和反馈回流的可复制研究命令。
